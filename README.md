# 🧭 Wanderlust AI — Autonomous Travel Itinerary Planner

An autonomous multi-agent travel planning system built with **LangChain**, **Mistral AI**, and **Streamlit**. It searches the live web for attractions, scrapes verified details (timings, pricing, activities), and synthesizes a tailored day-by-day itinerary based on user preferences and trip duration.

---

## 🚀 Features

- **Live Web Discovery:** Uses the **Tavily Search API** to fetch up-to-date travel recommendations, events, and attraction links.
- **Autonomous Web Scraping:** Extracts clean text from web pages via **BeautifulSoup**, stripping out ads, navigation, and boilerplate.
- **LLM-Powered Synthesis:** Uses **Mistral AI** (`mistral-small-latest`) via LangChain to compile structured, practical itineraries.
- **Modern Vintage Dark UI:** Custom styled **Streamlit** dashboard with deep black aesthetics and vintage amber accents.
